## 👋 Sobre mí

Ingeniero Informático por la **Universidad de Extremadura** (especialidad Ingeniería del Software). Me gusta construir cosas que funcionen de principio a fin: desde la base de datos y la API hasta el despliegue con Docker.

- 🔧 Trabajo sobre todo con **Python, Java y C#**, bases de datos relacionales y entornos **Linux**
- 🧠 En mi TFG he desarrollado una librería y una aplicación web para **procesar y clasificar señales EEG con IA**
- 🌱 Ahora mismo aprendiendo: self-hosting, automatización y electrónica con **ESP32**
- 🎾 Fuera del código: pádel y deporte
